# Faxineiro Acrobático

Jogo de ação e plataforma 2D pelas ruas de Parnamirim, feito em Godot.

## Jogar

**[Abrir o jogo no navegador](https://marxb50.github.io/jogo-varredor/)**

No celular, use as setas e os botões **PULO**, **VARRER**, **GIRO** e **POGO**. A tela horizontal oferece a melhor experiência.

No computador:

- Setas ou A/D: mover
- Espaço, Z ou seta para cima: pular
- X ou K: varrer
- C: golpe giratório
- Baixo + X no ar: pogo
- Shift: correr
